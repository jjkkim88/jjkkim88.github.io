**파이널 판타지 XII 인터내셔널 조디악 잡 시스템(Final Fantasy XII International Zodiac Job System)**은 스퀘어 에닉스가 개발·발매한 PS2용 액션 RPG입니다. 2006년 발매된 **파이널 판타지 XII**의 국제판으로, **12가지 조디악 잡(직업) 시스템**, **2배속 모드**, **트라이얼 모드** 등 방대한 추가 요소를 더해 2007년 일본에서 발매되었습니다.

FF 시리즈 사상 최초로 **완전 실시간 전투(ADB: Active Dimension Battle)**를 채택하고, **감비트(Gambit) 시스템**으로 파티원 AI를 직접 프로그래밍하는 전략성이 핵심입니다. 이반스 왕국을 배경으로 한 **정치 드라마** 서사와 방대한 오픈 월드 구성은 당시 PS2 RPG 최고 수준의 완성도로 평가받습니다.

## 📖 스토리

### 이반스 왕국과 두 제국 사이

무대는 **이발리스(Ivalice)** 세계의 **이반스 왕국(Kingdom of Dalmasca)**. 대국 아르카디아 제국과 로자리아 제국 사이에 낀 소왕국 이반스는 아르카디아의 침략으로 멸망하고, 수도 라바나스타는 제국 지배하에 놓입니다.

### 주인공 — 벤트와 아셀리아

| 인물 | 설명 |
|------|------|
| **벤트 (Vaan)** | 라바나스타 출신 고아 소년. 하늘을 자유로이 나는 하늘배 선장을 꿈꿈 |
| **아셀리아 (Ashe)** | 이반스 왕국의 공주. 저항군의 실질적 지도자. 왕국 재건을 위해 싸움 |
| **발피어 (Balflear)** | 하늘배 선장. 벤트의 동경의 대상이자 동료 |
| **판넬 (Fran)** | 발피어의 파트너. 장궁 사용. 뱅가 족 출신 |
| **바슈 (Basch)** | 이반스 왕의 친위대장. 반역자 누명을 쓰고 투옥된 기사 |
| **페넬로 (Penelo)** | 벤트의 소꿉친구. 댄서 지망생 |

### 스토리의 핵심 — 력의 석판과 운명

이반스 왕국 재건을 꿈꾸는 아셀리아가 **력의 석판(Sun-cryst)**을 향해 동료들과 여정을 떠납니다. 그 이면에는 **신이 짜놓은 역사의 흐름**을 지키려는 심판자들과, 역사를 바꾸려는 인간의 의지 사이의 대립이라는 철학적 주제가 깔려 있습니다.

## ⚙️ 핵심 시스템

### ADB — 실시간 전투

FF12는 시리즈 최초의 **완전 실시간 전투(Active Dimension Battle)**를 채택했습니다. 필드와 전투가 분리되지 않고, 몬스터가 필드에 배치된 상태에서 직접 접근해 전투가 시작됩니다.

| 요소 | 내용 |
|------|------|
| 전투 진입 | 인카운터 없음. 필드의 몬스터에게 직접 공격 |
| 커맨드 입력 | 전투 중 CT(차지 타임)를 기다려 행동 |
| 파티 | 최대 6인 파티 (전선 3인 조작, 후선 3인 대기) |
| 도망 | 적 범위에서 벗어나면 전투 종료 |

### 감비트 (Gambit) 시스템

FF12 최대의 특징인 **감비트**는 파티원의 행동을 **조건 + 행동 우선순위 목록**으로 설정하는 AI 프로그래밍 시스템입니다.

| 감비트 예시 | 설명 |
|------------|------|
| 아군 HP < 50% → 케알가 | 아군 체력이 반 이하면 힐 시전 |
| 적 약점 = 불 → 파이가 | 불 약점 적에게 파이가 자동 시전 |
| 적 (가장 가까운) → 공격 | 가장 근접한 적에게 자동 공격 |
| 아군 상태이상 → 에스나 | 아군의 상태이상 자동 해제 |

감비트를 잘 설정한 파티는 **반자동으로 던전을 공략**할 수 있으며, 전략적 감비트 구성이 이 게임의 핵심 재미입니다.

## 🃏 조디악 잡 시스템 (Zodiac Job System)

인터내셔널판의 핵심 추가 요소. 원작의 자유 라이센스 보드 대신 **12가지 직업(잡)**을 도입하고, 캐릭터마다 **직업을 선택**해 해당 직업의 라이센스 보드를 해금하는 방식입니다.

| 잡 | 사용 무기 | 특징 |
|----|----------|------|
| **나이트 (Knight)** | 검·방패 | 탱커. 고HP·고방어 |
| **몽크 (Monk)** | 봉·손발 | 근접 물리. 고공격력 |
| **화이트 매직 (White Mage)** | 봉·지팡이 | 회복·보조 마법 특화 |
| **블랙 매직 (Black Mage)** | 지팡이 | 공격 마법 특화 |
| **타임 배틀마지 (Time Battlemage)** | 석궁·봉 | 시간 마법·지원 |
| **레드 배틀마지 (Red Battlemage)** | 마법검 | 물리+마법 복합 |
| **나이트블레이드 (Knight of the Round)** | 닌자도·단검 | 고속 근접. 상태이상 특화 |
| **아처 (Archer)** | 활·장궁 | 원거리 물리 |
| **쇼트 (Shikari)** | 단검·수리검 | 고회피·속도형 |
| **버서커 (Bushi)** | 일본도 | 고공격력 근접 |
| **마키나리스트 (Machinist)** | 총기·수리검 | 원거리. 도구 특화 |
| **풀러 (Foebreaker)** | 도끼·해머 | 적 능력 강화 감소 |

인터내셔널판에서는 캐릭터 1인당 **잡을 1개 선택** (조디악 에이지에서는 2개로 확장). 잡 선택이 캐릭터의 장비·마법 전체를 결정하므로 파티 구성 시 **잡 분배 전략**이 중요합니다.

## 📋 라이센스 보드 (License Board)

각 캐릭터의 능력·장비·마법은 **라이센스 보드**에서 LP(라이센스 포인트)를 소비해 해금합니다. 조디악 잡 시스템에서는 **선택한 잡의 보드만 해금 가능**합니다.

| 해금 항목 | 내용 |
|----------|------|
| 무기·방어구 장착 | 해당 잡 전용 무기·방어구 해금 |
| 마법 | 화이트·블랙·그린 등 마법류 해금 |
| 액세서리 | 공통 액세서리는 잡 무관하게 해금 가능 |
| 오거먼트 | HP+·MP+ 등 파라미터 강화 패시브 |
| 퀵닝 | 잡별 오리지널 리미트 브레이크 해금 |

LP는 전투로 획득하며, 잡의 라이센스 보드를 완성하면 해당 직업의 모든 장비·스킬을 사용할 수 있게 됩니다.

## 🏆 트라이얼 모드 (Trial Mode)

인터내셔널판 추가 콘텐츠. **100개 연속 배틀**을 클리어하는 도전 모드입니다.

| 항목 | 내용 |
|------|------|
| 구성 | 100스테이지 연속 배틀. 라운드당 몬스터 구성 고정 |
| 보상 | 클리어 시 희귀 아이템·장비 드롭 |
| 난이도 | 후반 스테이지(90~100)는 최강 몬스터·보스 연속 등장 |
| 세이브 | 각 스테이지 클리어 후 일시 저장 가능 |

트라이얼 모드는 본편에서 입수하기 어려운 **최강 장비를 선행 입수**할 수 있는 루트이기도 합니다.

## 🌍 이발리스의 세계

FF12의 무대 **이발리스(Ivalice)**는 스퀘어 에닉스의 마츠노 야스미가 설계한 세계관으로, **파이널 판타지 택틱스**, **바그란트 스토리** 등과 세계관을 공유합니다.

| 지역 | 특징 |
|------|------|
| **라바나스타 (Rabanastre)** | 이반스 왕국의 수도. 게임의 시작점 |
| **오스타니아 사막** | 광대한 사막 지대. 다수의 공중성 부유 |
| **아르카디아 제국** | 가장 강대한 제국. 최종 대립 세력 |
| **그레이트 크리스탈** | 석판을 품은 거대 크리스탈 던전 |

## 💡 공략 팁

### 1. 잡 선택은 파티 전체를 고려해 분배

조디악 잡은 한 번 결정하면 변경이 불가합니다 (인터내셔널판 기준). 특히 **화이트 매직(회복)과 블랙 매직(공격)**은 1인씩 확보하는 것이 기본입니다. 탱커(나이트·몽크), 딜러(버서커·쇼트), 서포트(화이트·타임 배틀마지)의 균형을 맞춰서 파티 6인의 잡을 배분하세요.

### 2. 감비트는 초반부터 적극 설정

감비트 슬롯은 초반에 잠겨 있지만, 해금될 때마다 즉시 설정하세요. 특히 **케알가(HP 50% 이하 → 힐)** 감비트를 빠르게 설정하면 수동 조작 부담이 크게 줄어듭니다. 복수의 파티원에 힐 감비트를 분산하면 MP 낭비를 줄일 수 있습니다.

### 3. 헌트(몬스터 수배) 퀘스트를 병행

각 지역 마을의 **클랜 사무소(Clan Primer)**에서 몬스터 수배 의뢰(헌트)를 받을 수 있습니다. 헌트 클리어로 보수금과 희귀 아이템을 얻을 수 있고, 본편 스토리와 병행하면 레벨과 장비를 균형 있게 올릴 수 있습니다.

### 4. 2배속 모드를 적극 활용

인터내셔널판 추가 기능인 **2배속 모드**를 활용하면 레벨 파밍·이동이 크게 단축됩니다. 감비트 자동 전투 + 2배속 조합은 광역 파밍 시 매우 효율적입니다. L3 버튼(왼쪽 스틱 클릭) 한 번으로 토글됩니다.

### 5. 에스프레시온(소환수) 해금은 서브 던전 공략 필수

각 소환수(에스프레시온)는 **숨겨진 서브 던전 보스를 쓰러뜨려야 해금**됩니다. 파티 레벨이 높아진 뒤 도전해야 하는 보스가 많으므로, 메인 스토리 클리어 후 본격적으로 수집하는 것을 권장합니다.

### 6. 트라이얼 모드는 희귀 장비 선행 입수 루트

트라이얼 모드의 초반 스테이지(1~40)에서 본편보다 일찍 강력한 장비를 드롭받을 수 있습니다. 트라이얼 세이브 파일로 본편에 아이템을 반입할 수 있으므로, 막힌 던전이 있다면 트라이얼에서 장비를 먼저 확보하는 전략도 유효합니다.
